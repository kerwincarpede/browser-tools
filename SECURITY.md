# Security policy

## Reporting a vulnerability

Please don't open a public issue for security problems. Report them privately through
[GitHub's private vulnerability reporting](https://github.com/kerwincarpede/browser-tools/security/advisories/new)
instead.

Include the affected extension and version, steps to reproduce, and the impact you expect.
You should hear back within a week.

## Supported versions

Only the latest released version of each extension gets security fixes.
